# Quick Start Guide

## Get Started in 3 Steps!

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Application
```bash
cd backend
python app.py
```

### 3. Open in Browser
Navigate to: **http://127.0.0.1:5000**

## First Time Use

Click the **"Try Sample Data"** button on the home page to see the system in action immediately!

## What You'll See

✅ **Analytics Dashboard** - Real-time statistics and beautiful charts  
✅ **Predictions** - AI-powered 24-hour forecasts  
✅ **Recommendations** - Smart optimization strategies
